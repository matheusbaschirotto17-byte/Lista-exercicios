# Lista de revisão - Python

Cada questão está em sua própria pasta (`q01` até `q10`).

Para executar, abra o terminal dentro da pasta da questão e rode o arquivo indicado:

- q01: `python mochila.py`
- q02: `python excursao.py`
- q03: `python carrinho.py`
- q04: `python maratona.py`
- q05: `python sorteio.py`
- q06: `python devolucoes.py`
- q07: `python catalogo.py`
- q08: `python agenda.py`
- q09: `python estoque.py`
- q10: `python cineflix.py`

As questões 7 e 10 usam `catalogo.json`. Como o ZIP mencionado no PDF não veio junto, foi incluído um catálogo de exemplo com 15 títulos para os programas funcionarem. Se você receber o `catalogo.json` original da atividade, substitua os arquivos das pastas `q07` e `q10` por ele.
